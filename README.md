# Flashcard Quiz App

A simple and interactive Flashcard Quiz App built with React Native and Expo.

## Features

* Question and answer flashcards
* 3D flip animation
* Tap the card to reveal the answer
* Next and Previous navigation
* Add new flashcards
* Edit flashcards
* Delete flashcards
* Simple and clean user interface

## Technology Used

* React Native
* Expo Snack
* JavaScript

This project was created as part of the CodeAlpha internship task.
